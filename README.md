# Diagrammer Skill

A Claude skill for creating clear, structured diagrams to communicate systems, workflows, and ideas.

## Repository contents

- `SKILL.md`: the original diagramming skill instructions.

## Usage

Install this skill in the skills directory used by your Claude-compatible environment. Keep `SKILL.md` at the skill root.

Use it when you need to plan or produce diagrams that make complex information easier to understand.
